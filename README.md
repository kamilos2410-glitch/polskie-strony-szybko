# SCS Web – website for a small web design studio

Marketing website for **SCS Web**, my one-person studio that builds websites for small local businesses in Poland (plumbers, electricians, roofers, car workshops, construction companies).

**Live:** https://scsweb.pl

## Features

- Home page with the process, portfolio, pricing and FAQ
- Service, package and industry landing pages (plumber, electrician, roofer, car workshop, construction)
- Local landing pages for towns south-west of Warsaw (Tarczyn, Grójec, Piaseczno, Pruszków and more)
- Three fictional demo websites (plumber, car workshop, roofer) that show clients what they get
- Pricing calculator
- References section with scans of signed client references
- Contact form sent through Web3Forms (no backend)
- Technical SEO: per-page meta tags, Open Graph, JSON-LD, sitemap, prerendered pages, custom 404
- Mobile-first layout with a sticky call bar on phones

## Tech stack

React 19 · TypeScript · TanStack Start / Router · Vite · Tailwind CSS v4 · shadcn/ui (Radix UI) · Web3Forms

Built with [Lovable](https://lovable.dev).

## Running locally

```sh
npm install
npm run dev
```
